# План: русская озвучка лекции

Источник: локально в `audio-source/LECTURE_1/` (видео только как звук + `captions.sbv`). В git этих файлов нет.  
Продукт: **аудио**. Видео не меняем.

Конечная цель: этот диктор читает лекцию **по-русски своим голосом** (клон тембра).  
До клона доходим через простой рабочий пайплайн.

## Стек

Python — да. Тот же контур, что в соседнем [`mkv-ru-subs`](../mkv-ru-subs):

| Слой | Что |
|---|---|
| Язык | Python 3.12, venv |
| OpenAI SDK | `openai` с `base_url` прокси |
| Прокси | `https://spoken-word.info/openai-proxy/v1` (Амстердам, см. `amster/openai-proxy`) |
| Ключ клиента | токен прокси в `OPENAI_API_KEY`, не `sk-proj-` |
| Перевод | `gpt-5.6-luna` |
| TTS этап 1 | OpenAI `audio.speech` через тот же прокси |
| Аудио | `ffmpeg` / `ffprobe` |
| Конфиг | `.env` + `python-dotenv`, pydantic |

Не тащим Node, не ходим в `api.openai.com`.

## Этап 1 — просто русский звук (делаем первым)

Не заморачиваемся английским фоном.

1. Достать wav из MP4.
2. Разобрать SBV, склеить рваные реплики в фразы.
3. Отделить речь от песен (для пробы можно вручную взять 1–2 минуты речи).
4. Почистить ASR на речи.
5. Перевести сегменты пакетами через прокси (как `mkv-ru-subs`: JSON `{id, text}`, без таймкодов в модель, глоссарий имён).
6. Озвучить OpenAI TTS по сегментам.
7. Склеить: **речь = только русский TTS**, **песни = оригинал 1:1**.

Критерий: 2 минуты, потом весь файл `output/lecture_ru.wav`.

## Этап 2 — тихий английский с паузами

Тот же таймлайн, другая смесь на речевых кусках:

- русский сверху, английский тихо (~−16…−20 дБ);
- если русский длиннее — **пауза английской дорожки**, русский договаривает, потом следующий кусок EN;
- если русский короче — не даём EN уехать вперёд, хвост обрезаем.

Песни по-прежнему без перевода. Режим «только русский» остаётся флагом той же сборки.

## Этап 3 — цель: голос лектора

Заменить stock TTS на клон тембра. Текст, сегменты и микс те же.

Предпочтительно multilingual clone (сразу русский его голосом). RVC как запас хуже на русских фонемах у английского спикера. Песни в клон не тащим. Видео и lip-sync не делаем.

## Порядок кода

1. Каркас CLI + `--check` — сделано (`make_ru_voice.py`).
2. Проба 5 минут: перевод → TTS → склейка без EN-фона — сделано (`output/lecture_ru_0_300s.mp3`).
3. Если проба ок: полный перевод (можно отдельно от TTS) и озвучка дальше.
4. Микс с английским и паузами.
5. Клон на том же коротком куске.
